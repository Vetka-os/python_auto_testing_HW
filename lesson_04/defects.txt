Баг-репорт 1: Метод trim падает с ошибкой при передаче None
Приоритет: Medium
Серьезность: Major

Шаги воспроизведения:
1. Вызвать метод trim(None)
Ожидаемый результат: Метод должен возвращать пустую строку "" или выбрасывать понятное исключение (TypeError с сообщением "Ожидалась строка").
Фактический результат: Метод падает с необработанным исключением AttributeError: 'NoneType' object has no attribute 'startswith'.

Баг-репорт 2: Метод contains падает с ошибкой при передаче None
Приоритет: Medium
Серьезность: Major

Шаги воспроизведения:
1. Вызвать метод contains(None, "S")
Ожидаемый результат: Метод должен корректно обрабатывать пустые значения или выбрасывать TypeError.
Фактический результат: Метод падает с необработанным исключением AttributeError: 'NoneType' object has no attribute 'index'.

Баг-репорт 3: Метод delete_symbol падает с ошибкой при передаче None
Приоритет: Medium
Серьезность: Major

Шаги воспроизведения:
1. Вызвать метод delete_symbol(None, "S")
